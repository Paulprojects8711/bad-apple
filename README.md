# bad-apple
bad apple in cli (c++) using opencv and other magic witchcraft

## Build
Make sure you have:
- OpenCV (prebuilt binary for example)
- CMake
- compiler (g++ / clang / MSVC)
### Linux
```
mkdir build
cd build
cmake ..
make
```

### Windows
```
mkdir build
cd build cmake ..
cmake --build .
```
On Windows, you need opencv_worldXXX.dll in the same folder as the executable
